# Demo files

## Peak-Hold Waterfall Demo

[Download the demo blend](DH%20Audio%20Toolkit%20Peak%20Hold%20Waterfall%20Demo.blend)

Open in Blender 5.2+, assign a Sound datablock to the Analyzer node, and play
from frame 1. The file contains the verified Analyzer → Temporal Response →
Spectrum Points → Spectrum History Surface workflow with labeled stages and an
in-file usage note.

Rebuild it with `tools/create_peak_hold_waterfall_demo.py` if the toolkit
interface changes.
